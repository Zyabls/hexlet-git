T3MP3ST: офлайн-установка готового LXC-шаблона в Proxmox
================================================================

Внутри уже находятся Debian 12, Node.js 24.16.0, npm-зависимости,
собранный T3MP3ST и Codex CLI 0.146.0. На узле Proxmox интернет не нужен.

1. Скопируйте файл .tar.zst на узел Proxmox и проверьте SHA-256:

   sha256sum -c t3mp3st-debian12-pve-offline-amd64-afc9dad1.tar.zst.sha256
   install -m 0644 t3mp3st-debian12-pve-offline-amd64-afc9dad1.tar.zst \
     /var/lib/vz/template/cache/

2. Создайте контейнер. Замените 240, хранилища, мост и путь к ключу при необходимости:

   pct create 240 local:vztmpl/t3mp3st-debian12-pve-offline-amd64-afc9dad1.tar.zst \
     --hostname t3mp3st \
     --unprivileged 1 \
     --cores 4 \
     --memory 8192 \
     --swap 2048 \
     --rootfs local-lvm:100 \
     --net0 name=eth0,bridge=vmbr0,ip=dhcp,firewall=1 \
     --ssh-public-keys /root/.ssh/authorized_keys \
     --onboot 1 \
     --start 1

   Для статического адреса замените ip=dhcp на, например:
   ip=10.10.20.40/24,gw=10.10.20.1

3. Проверьте запуск:

   pct exec 240 -- systemctl is-active t3mp3st
   pct exec 240 -- systemctl --no-pager --full status t3mp3st
   pct exec 240 -- /usr/local/bin/node --version
   pct exec 240 -- /usr/local/bin/codex --version

4. Веб-интерфейс слушает только 127.0.0.1 контейнера. Откройте SSH-туннель:

   ssh -L 3333:127.0.0.1:3333 t3admin@IP_КОНТЕЙНЕРА

   Затем откройте http://127.0.0.1:3333/ui

Пароля по умолчанию нет: вход только по SSH-ключу, который передан через
--ssh-public-keys. Если ключ не передали, добавьте его через pct exec или консоль.

В образ намеренно не включены API-ключи и ~/.codex/auth.json. Авторизацию Codex
выполняйте приватно после развёртывания. Для установки шаблона интернет не нужен,
но для обращения к облачной модели Codex контейнеру потребуется разрешённый доступ
к соответствующему API.
