T3MP3ST Free AI: офлайн-установка готового LXC-шаблона в Proxmox
=======================================================================

Внутри уже находятся Debian 12, Node.js 24.16.0, npm-зависимости,
собранный T3MP3ST, Codex CLI 0.146.0, CPU-only Ollama 0.32.5 и локальная
Qwen2.5-Coder 1.5B. На узле Proxmox интернет не нужен даже для локальной LLM.

1. Скопируйте файл .tar.zst на узел Proxmox и проверьте SHA-256:

   Если Release содержит части .part-00, .part-01 и т.д., сначала соберите их:

   cat t3mp3st-freeai-debian12-pve-offline-amd64-afc9dad1.tar.zst.part-* \
     > t3mp3st-freeai-debian12-pve-offline-amd64-afc9dad1.tar.zst

   Затем проверьте и установите шаблон:

   sha256sum -c t3mp3st-freeai-debian12-pve-offline-amd64-afc9dad1.tar.zst.sha256
   install -m 0644 t3mp3st-freeai-debian12-pve-offline-amd64-afc9dad1.tar.zst \
     /var/lib/vz/template/cache/

2. Создайте контейнер. Замените 240, хранилища, мост и путь к ключу при необходимости:

   pct create 240 local:vztmpl/t3mp3st-freeai-debian12-pve-offline-amd64-afc9dad1.tar.zst \
     --hostname t3mp3st \
     --unprivileged 1 \
     --cores 4 \
     --memory 8192 \
     --swap 2048 \
     --rootfs local-lvm:100 \
     --net0 name=eth0,bridge=vmbr0,ip=dhcp,firewall=1 \
     --ssh-public-keys /root/.ssh/authorized_keys \
     --onboot 1 \
     --start 1

   Для статического адреса замените ip=dhcp на, например:
   ip=10.10.20.40/24,gw=10.10.20.1

3. Проверьте запуск:

   pct exec 240 -- systemctl is-active t3mp3st
   pct exec 240 -- systemctl --no-pager --full status t3mp3st
   pct exec 240 -- /usr/local/bin/node --version
   pct exec 240 -- /usr/local/bin/codex --version
   pct exec 240 -- /usr/local/bin/ollama list
   pct exec 240 -- /usr/local/sbin/t3mp3st-free-ai status

4. Веб-интерфейс слушает только 127.0.0.1 контейнера. Откройте SSH-туннель:

   ssh -L 3333:127.0.0.1:3333 t3admin@IP_КОНТЕЙНЕРА

   Затем откройте http://127.0.0.1:3333/ui

Пароля по умолчанию нет: вход только по SSH-ключу, который передан через
--ssh-public-keys. Если ключ не передали, добавьте его через pct exec или консоль.

В образ намеренно не включены API-ключи и ~/.codex/auth.json. Авторизацию Codex
выполняйте приватно после развёртывания из консоли контейнера:

   sudo t3mp3st-free-ai codex-login

Это вход ChatGPT, а не Platform API key: отдельные API-начисления не создаются,
но действуют лимиты вашего плана ChatGPT. Полностью автономный режим уже готов:

   sudo t3mp3st-free-ai local

Вернуться на Codex:

   sudo t3mp3st-free-ai codex

Для установки и локальной Qwen интернет не нужен. Для Codex контейнеру потребуется
доступ к сервисам OpenAI. Все агенты используйте только в разрешённом контуре.
