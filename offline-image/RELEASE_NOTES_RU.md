Готовый незашифрованный LXC rootfs-шаблон для Proxmox VE. Это не установщик: Debian 12, Node.js 24.16.0, npm-зависимости, собранный T3MP3ST (`afc9dad1`) и Codex CLI 0.146.0 уже находятся внутри.

Для установки на изолированном узле Proxmox достаточно перенести `.tar.zst` и файл контрольной суммы. Команды находятся в `INSTALL_PROXMOX_RU.txt`.

В образ не включены пароли, API-ключи и авторизация Codex. Администратор `t3admin` получает публичный ключ, переданный Proxmox через `pct create --ssh-public-keys`.
